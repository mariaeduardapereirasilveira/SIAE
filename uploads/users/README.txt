SIAE - armazenamento persistente de fotos de usuários

As imagens enviadas pelo sistema são gravadas aqui, enquanto o banco de dados guarda somente o caminho relativo (uploads/users/nome-gerado.ext).

IMPORTANTE: ao migrar, copiar ou substituir a pasta SIAE, preserve os arquivos desta pasta junto com o banco de dados. Os arquivos de fotos criados em tempo de execução não acompanham o ZIP do código-fonte.
